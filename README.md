# Password Strength Checker

A lightweight Python application designed to evaluate password strength and enforce credential hygiene. Built with a clean, basic graphical user interface (GUI) for ease of use and immediate visual feedback.

## Features

* **Interactive GUI**: User-friendly desktop interface for entering credentials without interacting with the terminal.
* **Complexity Evaluation**: Checks for standard security criteria including:
  * Minimum character length
  * Lowercase and uppercase letters
  * Numerical digits
  * Special characters / symbols
* **Real-Time Feedback**: Clear indicators showing whether a passphrase qualifies as weak, moderate, or strong.

## Prerequisites

* Python 3.8+ installed on your system.
* Standard Python GUI libraries (e.g., `tkinter`, which comes pre-installed with standard Python distributions on Windows).
